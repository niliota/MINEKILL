# UltraCraft bridge protocol, version 1

Generated from `bridge/protocol/generate.py`. Do not edit this file by hand.

Total mapped file size: **3035640 bytes**. All fields little-endian, all
records 8-byte aligned. `bool` is one byte on the wire in both languages.

## Slots (seqlock)

Each slot is `uint seq`, payload, `uint seqEnd`. The writer sets `seq` to an odd
number before writing and back to the matching even number when done. A reader that
sees different values, or an odd value, retries. A slot is always *latest value wins*;
nothing is queued here.

## Ring buffers

dropped counter, because a stale slot is worse than a lost event.

## Tables (one seqlock over a list)

`u32 seq` at offset 0, a fixed header, then up to `capacity` records. The writer
makes `seq` odd, writes header and records, then makes it even. The reader copies the
header and `count` records and discards the copy if `seq` changed or was odd.
